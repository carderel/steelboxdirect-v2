# $99 RTO Down Payment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish My Container Rental's new $99 RTO down payment across the site from one canonical module, with its condition inseparable from the offer.

**Architecture:** One data module owns the figures and the disclosure string. Every surface reads from it. A new city-page CTA component renders headline and small print as an indivisible unit. Two compliance guards make hand-typing the figure, or shipping the offer without its condition, fail the build.

**Tech Stack:** Astro 4, TypeScript, vitest, Cloudflare Pages.

**Spec:** `docs/superpowers/specs/2026-08-31-rto-99-down-design.md`

## Global Constraints

- **NO em dashes or en dashes anywhere.** `src/lib/compliance/dash-guard.test.ts` fails the build.
- **NEVER hand-type a dollar amount.** Every `$99` and `20%` string must come from `src/data/rtoTerms.ts`.
- **DO NOT touch application or approval wording.** Owner ruling 2026-08-28: Doug's memo says no application is needed, observable reality says otherwise, SBD keeps its existing wording. Every "application" and "subject to third-party approval" string on `/rent-to-own/` stays byte-identical.
- **The 150 miles is measured from the DEPOT the container ships from, NOT from Cincinnati.** Never introduce a Cincinnati-relative or per-city distance claim.
- **The offer never renders without its condition.** Task 3's guard enforces this.
- **Effective date is 2026-09-01.** State it; do not imply the term was always active.
- **Attribute the program to My Container Rental**, not to Steel Box Direct.
- **The June volume claim is My Container Rental's**, stated as "roughly doubled". Never restate it as an SBD statistic and never convert it to a percentage.
- All dynamic routes need `export const prerender = true`.
- Run `npx vitest run` after every task. Baseline is 459 passing.

```ts
// src/data/rtoTerms.ts
// The single canonical statement of My Container Rental's rent-to-own down payment terms.
//
// WHY THIS IS A MODULE AND NOT PAGE COPY, in order of force.
//   1. $99 is a dollar amount, and hand-typing a dollar amount is a hard stop on this project.
//   2. It will change. It replaced a 10% requirement on 2026-09-01 and is the second revision
//      this year. One edit here, not twenty across the site.
//   3. The disclosure must not drift. If each page writes its own version of the distance
//      condition they will diverge, and a page that states the offer without its condition is a
//      false claim. Consumers take the composed strings, not the parts.
//
// Same rule as rentalStance.ts: the FACT never forks, the WRAPPER always differs.
//
// TWO THINGS THAT ARE EASY TO GET WRONG AND WERE GOT WRONG ONCE.
//   The 150 miles is measured from the DEPOT the container ships from, NOT from Cincinnati.
//   Containers ship nationwide from depot hubs, so a buyer far from Ohio is not automatically
//   outside the $99 tier. Never reintroduce a Cincinnati-relative claim.
//
//   Doug's 2026-08-28 announcement says no application or special approval is needed. The owner
//   verified that everything observable still requires an application and ruled that the site
//   keeps its existing wording. This module therefore says nothing about applications, and
//   nothing here licenses removing the approval language from /rent-to-own/.

export const RTO_TERMS = {
  /** Standard-container down payment inside the distance limit. */
  downPayment: '$99',
  /** Down payment beyond the distance limit, and on modified or specialty units. */
  remoteDownPayment: '20%',
  /** Miles from the shipping depot, not from Cincinnati. */
  distanceLimitMiles: '150',
  /** ISO date the terms take effect. */
  effectiveDate: '2026-09-01',
  /** The independent third party that administers the program. Not Steel Box Direct. */
  provider: 'My Container Rental',
} as const;

/**
 * The canonical condition. Any surface stating the down payment states this with it.
 * Both tiers appear here deliberately: a reader who cannot get $99 learns what they can get.
 */
export const RTO_DOWN_CONDITION =
  `${RTO_TERMS.downPayment} applies to standard containers delivered within `
  + `${RTO_TERMS.distanceLimitMiles} miles of the depot your container ships from; `
  + `${RTO_TERMS.remoteDownPayment} down beyond that.`;

/** Owner-approved CTA headline, 2026-08-28. His words. Do not rewrite without asking him. */
export const RTO_CTA_HEADLINE =
  'Find out how you can get your shipping container for one easy down payment as low as '
  + `${RTO_TERMS.downPayment}!`;

/** Owner-approved CTA small print, with the depot correction folded in. */
export const RTO_CTA_SMALLPRINT =
  `Pending third-party approval. ${RTO_DOWN_CONDITION} `
  + 'Delivery distance also affects your monthly payment.';

/** Human-readable effective date, e.g. "September 1, 2026". */
export function rtoEffectiveDateLabel(): string {
  return new Date(`${RTO_TERMS.effectiveDate}T00:00:00`).toLocaleDateString('en-US', {
    month: 'long',
    day: 'numeric',
    year: 'numeric',
    timeZone: 'UTC',
  });
}
```

```ts
import { describe, it, expect } from 'vitest';
import { readFileSync, readdirSync, statSync } from 'node:fs';
import { join, relative, sep } from 'node:path';

const REPO_ROOT = join(import.meta.dirname, '..', '..', '..');
const CTA = 'src/components/RtoDownPaymentCta.astro';

function walk(dir: string, acc: string[] = []): string[] {
  for (const e of readdirSync(dir)) {
    const p = join(dir, e);
    if (statSync(p).isDirectory()) walk(p, acc);
    else if (/\.(astro|ts|md)$/.test(e)) acc.push(p);
  }
  return acc;
}
const rel = (p: string) => relative(REPO_ROOT, p).split(sep).join('/');

describe('rto terms guard: the figure is never typed, the offer never travels alone', () => {
  const files = walk(join(REPO_ROOT, 'src')).filter((f) => !/\.test\.ts$/.test(f));

  it('scans a non-trivial file set', () => {
    expect(files.length).toBeGreaterThan(50);
  });

  it('no file outside rtoTerms.ts hand-types the down payment figure', () => {
    const offenders = files
      .filter((f) => rel(f) !== 'src/data/rtoTerms.ts')
      .filter((f) => /\$99/.test(readFileSync(f, 'utf8')))
      .map(rel);
    expect(offenders).toEqual([]);
  });

  it('the CTA renders its small print in the same component as its headline', () => {
    const src = readFileSync(join(REPO_ROOT, CTA), 'utf8');
    expect(src).toContain('RTO_CTA_HEADLINE');
    expect(src).toContain('RTO_CTA_SMALLPRINT');
  });

  it('the CTA takes no props, so the small print cannot be switched off', () => {
    const src = readFileSync(join(REPO_ROOT, CTA), 'utf8');
    expect(src).not.toMatch(/Astro\.props/);
  });

  it('the CTA links into the rent-to-own down payment section', () => {
    const src = readFileSync(join(REPO_ROOT, CTA), 'utf8');
    expect(src).toContain('/rent-to-own/#down-payment');
  });
});
```
