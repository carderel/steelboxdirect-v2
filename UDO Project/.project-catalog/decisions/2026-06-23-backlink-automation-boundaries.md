# Decision — Backlink Automation Boundaries

## Context
The user is one person and needs help executing the backlink strategy.

## Decision
Automate research, organization, copy preparation, tracking, and on-site linkable assets. Do not automate account creation, paid memberships, sponsorships, outreach sending, review generation, or claims of partnership without explicit user approval.

## Rationale
This preserves speed while avoiding spam, unauthorized spending, credential exposure, fake relationships, and Google link-spam risk.

## Allowed Automation
- Prospect research.
- Tracker creation and maintenance.
- Profile copy and category recommendations.
- Outreach drafts.
- UTM generation.
- Linkable page/content drafts.
- Status reporting.

## Requires User Approval
- Account login/verification.
- Directory submissions.
- Chamber or association memberships.
- Paid sponsorships.
- Sending emails.
- Publishing public claims of partnership.
