## Direction (owner's thesis, assessed SOUND, ~80% confidence it's a sound path to START)
1. **Enter TRUST-FIRST** — impartial vetting/review directory (leads with the most-validated, unowned wedge).
2. **Build as SWEAT EQUITY** — hard out-of-pocket = domain + hosting only. This DISSOLVES the research's biggest open conflict: with no capital at stake, risk moves from "burn six figures" to "does authority accrue + will dealers pay." Better bootstrapper risk profile; can start and let the market answer.
3. **Morph to DATA-AUTHORITY platform** as authority/traffic/review-corpus accrue — same path VRTO took (VRTO = the proprietary cold-start analog neither external report examined).

## Required correction to "only domain + hosting"
A review/vetting site carries the highest legal surface. Non-optional (still cheap) legal wrapper:
- Single-member LLC + basic general-liability policy.
- HARD RULE: never AI-summarize user reviews (loses §230 immunity) — publish raw.
- FTC 16 CFR 465 = $53,088/violation (no fake/suppressed reviews; disclose paid placements).
- Plain-text dealer names only (no stylized logos).
- Cap Google Places API via field-masking (keeps DB sourcing in tens-of-dollars at pilot scale).
- Morph guardrail: keep the trust layer visibly clean as lead/badge monetization turns on (credibility conflict = the FTC risk).
