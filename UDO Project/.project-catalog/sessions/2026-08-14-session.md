## The three findings that mattered most

**A published PROJECT_HS_003 violation had been hiding inside an expected test failure for four days.** The suite
reported "1 failing, 2 findings" and everyone read that as the healthy state. One finding was a draft; the other
was live on `/blog/wind-and-water-tight-explained/` since 2026-07-06. Both now closed. **Promoted as L017.**

**`draft: true` does not mean not deployed.** Verified: the draft post's compiled content ships in three chunks
of the Cloudflare worker bundle even though no page renders. Draft content reaches production assets.

**The implementation plan was wrong nine times, every single time in a verification instruction rather than in
design.** `grep -c` against single-line built HTML (23 instances), an unachievable `Service` 0 expectation, 14
concatenated command blocks, a comment trap, unicode escapes landing as literal characters, a line-wrap trap, an
inverted array contract, whole-file link counts contaminated by chrome, and `git diff -U0 main` where `main` is
`HEAD`. The architecture held throughout. **Promoted as L016.**
