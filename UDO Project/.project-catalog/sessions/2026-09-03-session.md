email.

returns empty, while `supabase.co` and `steelboxdirect.com` both resolve, so local DNS is healthy. A
merely *paused* free-tier project still resolves and returns a paused error. No DNS record means the

thing it guarded died.

## OUTAGE 2: the pricing harvest gate has NEVER passed (T-209, FIX APPLIED, NOT COMMITTED)

Owner reported the harvest and watchdog failing since Aug 20. Confirmed exactly: last success
2026-08-19, first failure 2026-08-20, **15 consecutive failures**.

**Root cause proven.** The job runs `npx tsc --noEmit` **before** `astro build`. Astro's generated
types live in `.astro/`, which is gitignored and **not** in the job's cache. On a fresh runner they
do not exist. **All 20 runner errors are missing-generated-types. Zero are real defects.** Deleting
`.astro/` locally reproduces exactly 20; `npx astro sync` takes it to 0.

**Why Aug 20, and this is the worse half.** Every gate is conditional on
`harvest.outputs.status == 'written'`. The only green run, Aug 19, was a **no-op day**: the feed did
not move, so **every gate was skipped** (verified in that run's step list). Aug 20 was the first day
the feed moved, so it was the first time the type check ever executed, and it failed.
**The gate has never passed. The one green run tested nothing.**

**The watchdog is not broken.** It is the alarm working, and it has commented on GitHub issue #1
**every day since Aug 21**. The alerting worked; nobody was reading it.

**Measured drift, from a local harvest run: 99 changes across 15 of 15 metros.** Prices came DOWN and
the site never caught up, so buyers saw numbers materially too high:

| Metro | SKU | Site | Actual | Off by |
|---|---|---|---|---|
| Louisville | 40ft delivered | 3000 | 2430 | 23.5% |
| Lexington | 40ft delivered | 2910 | 2350 | 23.8% |
| Cincinnati | 40ft HC pickup | 1960 | 1700 | 15.3% |

**Compliance consequence, and the reason this is high priority.** CLAUDE.md permits average prices on
city pages *because* "a daily-verified feed cures staleness", which is what superseded the old
city-page hard stop. **That premise has been false for 16 days.** Live pages still read "These prices
have been in effect since August 18", which is literally true, which is exactly why no guard caught
it.

**Fix applied:** `npx astro sync` before the type check, with the 20-vs-0 measurement written into
the step comment so nobody drops it. All five gates now pass locally against fresh data: 652 tests,
60 harvest tests, 0 type errors, build exit 0.
