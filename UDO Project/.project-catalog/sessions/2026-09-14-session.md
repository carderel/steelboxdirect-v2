## 40ft framing: RESOLVED
- **Correction to my earlier diagnosis:** the 25% zoom did not cause the crop. Measured, the 40hc
  overflows to 1.219 NDC at the ORIGINAL preset with no tighten. The presets were tuned for an
  unexploded box. The approved 20ft framing also clips slightly (1.442), so "fit everything" was
  never the bar.
- **Fix:** removed the fixed zoom constant and added `frameModelToFill()`, which solves the orbit
  target (model bounding-box centre, which kills the dead space above the box) and the camera
  distance from the model's own bounds on every load. Three corrective passes, no unbounded loop.
  Per-model and per-viewport, so it survives changes to spread, fov, aspect or iframe size.
- `FRAME_FILL = 1.12`, tuned at the REAL iframe aspect (1280x560), not the near-square test window.
  Tighter values left the 20ft small; this lets extreme corners graze while the box reads large.
- Verified all three at 1280x560: whole, centred, only the 40hc outer door leaf grazes the bottom.
  Build clean, 708 tests. Still uncommitted.
