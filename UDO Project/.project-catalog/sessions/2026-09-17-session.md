## What happened

### The owner brought a Gemini plan for the 77 county permit pages
Gemini proposed a hybrid consolidation. Audited before acting. Right in shape, wrong in three
specifics, and two of them would have done damage:

1. **Hard stop violation.** It called for "unique, localized variations of our standard zoning
   guidelines" per county, with example H2s like "Montgomery County Storage Building Rules". That is
   a permit requirement stated for a named place. It is also unwritable honestly: `permitCounties.ts`
   derives from `cities.ts` and the only per-county datum in the repo is an office name, scope and
   URL. Writing 77 zoning sections means inventing 77 sets of rules.
2. **It would have deleted the site's only growth.** It named a "Big 7" metro list and proposed
   redirecting "thin micro-market location pages" into it. There are 15 city pages, and the other 8
   are depot metros. Location pages were 86% of the impression gain, Indianapolis alone 48%.
3. **It proposed building a page that exists.** `src/pages/permits/[state]/index.astro` was already
   live and already listed the counties.

Also flagged: renaming H2s to dodge a duplicate-content warning is cosmetic, not a fix.

Presented two real options. Owner chose A, consolidate.

### Built and shipped into the tree
One `astro-developer` pass, then an independent `verifier` pass.

- Each county is now an anchored `<section id="{slug}">` on its state hub, carrying only the office
  name, scope and link the data already held. Plain anchor jump list, no JS, no sticky positioning.
- `permits/[state]/[county].astro` deleted.
- 77 301s generated in `astro.config.mjs` from the data, no slug hand-typed.
- **The snag was not the one predicted.** The anchor survives Astro and the Cloudflare adapter fine.
  What broke is that Astro STRIPS A TRAILING SLASH off a redirect key, so keying both forms produced
  154 lines that were 77 rules written twice, with the slash form emitted nowhere. The old pages
  shipped with a trailing slash and Cloudflare treats the two paths as different. 77 slash companions
  now live in `public/_redirects`, matching how the four flat city URLs were already handled, with a
  guard that recomputes the block so it cannot drift.
- Tests 708 to 721. Sitemap 161 to 84, delta exactly -77, nothing non-permit lost.

### The hole it found
20 of the 49 guard assertions, **including the letter-for-letter anti-invention reconstruction**,
were `it.skipIf(!hasDist)`. Proven failure mode: move `dist/` aside and the file reports
"29 passed | 20 skipped" and looks green. `npm run build` never exercises the reconstruction either,
so the hard-stop protection existed only when someone ran `npm test` after a build.

This is the third time this project has hit the same failure class: the `grep --include=*.html` false
pass, the hidden footer text that every source-reading check missed for 120 days, and now this. A fix
is dispatched to make a missing `dist/` FAIL rather than skip, matching the pre-push gate's existing
stance that you cannot review output you have not built.
