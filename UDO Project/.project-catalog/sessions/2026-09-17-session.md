### THE DEFECT. Cloudflare Pages silently drops redirect rules past about 110.
`d78ce4a` shipped 166 rules in `dist/_redirects`. A production sweep of all 154 county rules found:

- all 77 TRAILING-SLASH forms served 301;
- 21 of 77 BARE forms served 301;
- **56 of 77 BARE forms returned 404.**

The break tracks POSITION IN THE FILE, not content. Rule 105 in file order worked, rule 109 did not.
110 of 166 honoured. **No build error, no deploy warning, no log line.** Nothing indexed was broken,
because the retired pages shipped with a trailing slash and every slash form worked, so this was 56
live 404s rather than lost equity. The real damage was a silent ceiling sitting under every redirect
this site adds from now on.

Found only because the 301s were swept against PRODUCTION. A local build cannot see this, and
`wrangler pages dev` cannot either: the local Pages runtime has no ceiling.

### The fix, `bae9a05`
154 static rules became **22 Cloudflare placeholder rules**, one per state per slash form. File is
down to **34 rules from 166**. Re-swept live: **154 of 154 forms 301 to the correct anchor, 0 broken**,
all 12 pre-existing rules intact, all 11 state pages 200 with 77 county sections between them.

Two findings worth carrying:
- **Placeholders must NOT go in `astro.config.mjs`.** `@astrojs/underscore-redirects` emits
  `status: 200` with an empty target for a dynamic redirect route with no `distURL`, so a `:county`
  key there produces a broken rule rather than a 301. `public/_redirects` is copied verbatim and the
  adapter only appends after it.
- **Per-state rules, not one `/permits/:state/:county` pair.** An invented STATE would otherwise 301
  into a page that does not exist. An invented county under a real state does 301 to its state page,
  which was accepted and made testable rather than commented.

A test now asserts `dist/_redirects` stays under 100 rules and names the ceiling in its failure
message, because the platform never will. Rules are resolved through a Cloudflare matcher rather than
looked up as strings, since a lookup cannot see through a placeholder and would report green on an
empty file. Every new assertion was mutation tested. 724 tests.

### The pattern this is the fourth instance of
A check that reports success while checking nothing: the `grep --include=*.html` false pass, the
hidden footer text that every source-reading check missed for 120 days, the 20 `skipIf(!hasDist)`
guard assertions closed earlier today, and now a platform that accepts 166 rules and applies 110.
The standing lesson is unchanged and now has a fourth data point: **verify against production, not
against the artifact you built.** The pre-push gate still scans `dist/`, not production. That gap is
now the single highest-value piece of debt on this list.
